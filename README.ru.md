# Slovorez

[English](https://github.com/heysonanderson/slovorez/blob/master/README.md) · **Русский**

Slovorez делает морфемный разбор русских слов. Модель 215к параметров, на CPU через ONNX Runtime. Токенизатор написан на C++.

Модель обучена на леммах слов. Со словоформами работа планируется в следующих версиях, см. «Ограничения».

## Пример

```python
from slovorez import Slovorez

model = Slovorez.from_pretrained()          # встроенная модель slovorez-flash
model.predict("перевыполнить, улыбаться")
```

```python
[{'word': 'перевыполнить',
  'morphemes': [['пере', 'PREF', 0.99], ['вы', 'PREF', 0.96], ['полн', 'ROOT', 0.99],
                ['и', 'SUFF', 1.0], ['ть', 'SUFF', 1.0]],
  'confidence': 0.95,
  'model': 'slovorez-flash'},
 {'word': 'улыбаться',
  'morphemes': [['улыб', 'ROOT', 0.86], ['а', 'SUFF', 0.99], ['ть', 'SUFF', 1.0],
                ['ся', 'POSTFIX', 1.0]],
  'confidence': 0.77,
  'model': 'slovorez-flash'}]
```

- `morphemes`: список `[текст, класс, уверенность]`.
- `confidence`: уверенность в разборе всего слова, от 0 до 1.
- Слова приводятся к нижнему регистру и идут в порядке текста, повторы не убираются. Разбирает только кириллицу.

Классы морфем:

| класс | значение |
|---|---|
| PREF | приставка |
| ROOT | корень |
| SUFF | суффикс |
| END | окончание |
| POSTFIX | постфикс |
| LINK | соединительная гласная (интерфикс) |
| HYPH | дефис |

Декодер Витерби допускает только правильные переходы между морфемами.

## Большие файлы

```python
model.process_file("text.txt")                     # в одном потоке
model.process_file("text.txt", threaded_mode=True) # инференс в нескольких потоках
```

Результат дописывается в jsonl, по записи на строку, в том же формате, что у `predict`. По умолчанию файл лежит в `~/.cache/slovorez/predictions/<модель>/<версия>/predictions.jsonl`. Папку меняет переменная `SLOVOREZ_HOME`, путь к файлу задаёт `from_pretrained(predictions_path=...)`.

Слова, которые уже есть в файле с прошлых запусков, пропускаются, поэтому прерванную обработку можно запустить заново. Перед разбором слова дедуплицируются.

Слова из встроенного словаря модели (`base_dict.json`, ≈96 тыс. лемм) `process_file` не размечает и в jsonl не пишет: их разбор уже есть в словаре.

## Установка

```bash
pip install slovorez
```

Готовые wheel есть для Python 3.10–3.13 на Linux, Windows и macOS (Apple Silicon). На других платформах и версиях Python pip собирает токенизатор из исходников, нужен компилятор C++ (на Windows это MSVC Build Tools). Python 3.10+.

## Качество

slovorez-flash, декодер Витерби. Метрики по `measure_quality` из Morozov et al. (2025), эталон — `base_dict` 0.2.0.

| Тест | F1 границ | F1 корня | Accuracy | Word Acc |
|---|---|---|---|---|
| Знакомые корни (отложенные 5 000 слов) | 95,69 | 87,15 | 92,53 | 75,50 |
| Новые корни (10 фолдов по группам корней) | 94,31 ± 0,43 | 81,95 ± 1,45 | 89,61 ± 0,82 | 69,42 ± 1,86 |

F1 границ: по всем границам морфем. F1 корня: по границам корней. Accuracy: по символам. Word Acc: доля слов, разобранных целиком верно. Во второй строке корни теста не встречались при обучении; там указано среднее ± стандартное отклонение по фолдам.

В 0.1.0 модель и тест были другие.

## Скорость

1M предложений русских новостей (Leipzig `rus_news_2023_1M`, 13,8M токенов), AMD Ryzen 7 5700X, Windows 10. Столбцы `process_file` - слов в секунду.

| | `process_file`, 1 поток | `process_file`, 8 воркеров | `predict`, мс | загрузка, с | память, МБ |
|---|---|---|---|---|---|
| slovorez 0.1.0 | 152K | 94K | 2,60 | 0,51 | 283 |
| slovorez 0.2.0 | **210K** | **396K** | **1,75** | **0,42** | **244** |

`predict` — медиана на одно предложение. Загрузка — `from_pretrained`. Память — пик памяти процесса.

Скорость зависит от размера корпуса: каждое уникальное слово уходит в модель один раз. Потолок — токенизатор, около 630K токенов/с. Полные таблицы (100K и 1M предложений, 2/4/8 воркеров, скорость одной модели, p95), окружение и методика — в [bench/README.md](https://github.com/heysonanderson/slovorez/blob/master/bench/README.md).

## Уверенность

`confidence` оценивает вероятность того, что слово разобрано целиком верно. На тестовых словах из раздела «Качество», если оставлять только слова выше порога:

| Порог | Осталось слов | word accuracy, random/root |
|---|---|---|
| нет | 100% | 75,5% / 69,4% |
| 0,7 | 56% | 91,1% / 84,1% |
| 0,8 | 43% | 94,5% / 87,9% |
| 0,9 | 26% | 97,6% / 92,8% |

На новых корнях выше 0,7 `confidence` немного завышена. Это измерено на леммах; на словоформах из реального текста `confidence` ниже.

## Ограничения

Проверено на тестах из `tests/` и на корпусах текста на одной машине (Windows). Под нагрузкой в продакшене и на слабых устройствах не проверялось.

- Модель обучена на леммах. Словоформы разбирает хуже, например `выделяются` → `вы|дел|я|ютс|я`.
- Слова длиннее 64 символов пропускаются без предупреждения.
- Токенизатор (C++): если в тексте есть цепочка из 9 и больше частей через дефис или слово длиннее 128 символов, весь текст после неё теряется.
- Слово через дефис в самом конце файла, без перевода строки после него, может потеряться. В `predict` это обойдено.
- Если `process_file` упал с исключением, создайте объект заново через `from_pretrained`. Слова, записанные до ошибки, сохраняются.
- Порядок записей в jsonl зависит от `PYTHONHASHSEED`.

## Как устроено

Модель предсказывает для каждой буквы метку BIES (начало, середина, конец морфемы или морфема из одной буквы) вместе с классом морфемы. Сеть: эмбеддинги букв, три слоя Conv1D (ядро 5), голова из свёрток 1×1. Токенизатор на C++ подключён через pybind11, инференс идёт через ONNX Runtime.
